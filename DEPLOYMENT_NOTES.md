## Deployment Steps

1. **First Time Setup:**
   ```bash
   # Install Fly CLI
   curl -L https://fly.io/install.sh | sh
   
   # Login
   fly auth login
   
   # Create app (if not exists)
   fly launch --no-deploy
   
   # Create and attach Postgres
   fly postgres create --name numbers-evolution-db --region fra
   fly postgres attach numbers-evolution-db
   
   # Set secrets
   fly secrets set SECRET_KEY_BASE=$(mix phx.gen.secret)
   fly secrets set OPENROUTER_API_KEY=your_key_here
   ```

2. **Deploy:**
   ```bash
   fly deploy
   ```

3. **GitHub Actions:**
   - Add FLY_API_TOKEN to GitHub Secrets (get with: fly auth token)
   - Push to master branch → automatic deployment

## Troubleshooting

If deployment fails:
1. Check logs: `fly logs`
2. Verify secrets: `fly secrets list`
3. Check DB connection: `fly postgres connect -a numbers-evolution-db`
4. Review release logs in Fly.io dashboard
